# metacopy

Утилита для macOS, которая копирует метаданные с оригинальной фотки на её обработанную версию.

Зачем это вообще. Я часто прогоняю фотки с айфона через нейронки: апскейл, ретушь, иногда что-то генерю поверх. На выходе почти всегда PNG без единого тега. Закидываешь такое в Фото, и оно улетает в сегодняшний день, без геолокации, без камеры, в общем мимо. Каждый раз вспоминать нужные флаги exiftool и чинить ориентацию руками мне надоело, поэтому написал вот это.

```
$ metacopy IMG_4821.HEIC upscaled.png
✓ IMG_4821.HEIC → upscaled.png
  Дата съёмки  2024-06-15 14:23:01 +03:00
  GPS          55.751244, 37.618423, высота 156 м
  Камера       Apple iPhone 15 Pro
  Объектив     iPhone 15 Pro back triple camera 6.765mm f/1.78
  MakerNotes   Apple, 41 тег
  Картинка     2048×1536 JPEG, Orientation=1, без превью
  Сохранено    /Users/me/Pictures/upscaled_meta.jpg
```

## Установка

Понадобится exiftool:

```sh
brew install exiftool
```

Python подойдёт любой от 3.8, системный тоже (сам гонял на 3.9 и 3.13). Ставить через pip ничего не нужно.

```sh
git clone https://github.com/macfluryy/metacopy.git
cd metacopy
ln -s "$PWD/metacopy" ~/.local/bin/metacopy
```

Если `~/.local/bin` у вас не в PATH:

```sh
mkdir -p ~/.local/bin
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

Можно и `sudo ln -s "$PWD/metacopy" /usr/local/bin/`, как удобнее. Только папку с репой потом не удаляйте, ссылка смотрит в неё.

Проверить, что всё встало: `metacopy --version`

## Использование

```
metacopy <оригинал> <обработанная> [-o куда] [--format auto|jpg|heic|keep]
```

По умолчанию результат ложится рядом с обработанной картинкой: `art.png` → `art_meta.jpg`. Сами файлы не меняются, вся работа идёт на временной копии.

```sh
metacopy IMG_1234.HEIC art.png                    # → art_meta.jpg рядом
metacopy IMG_1234.HEIC art.png -o ~/Desktop/      # в папку
metacopy IMG_1234.HEIC art.png -o sunset.jpg      # под своим именем
metacopy IMG_1234.HEIC art.png --format heic      # → art_meta.heic
metacopy IMG_1234.HEIC art.webp --format keep     # webp останется webp
```

Удобно: набираете `metacopy ` и перетаскиваете оба файла из Finder прямо в терминал, пути подставятся сами.

Готовый файл потом просто кидаете в Фото (или Файл → Импортировать), и он встаёт на дату оригинала и на карту.

### Флаги

| флаг | что делает |
|---|---|
| `-o PATH` | файл или папка. Папкой считается, если путь кончается на `/` или такая папка уже есть |
| `--format` | `auto` (дефолт): PNG, WEBP и всё прочее в JPEG, JPEG и HEIC не трогает. `jpg` / `heic`: принудительно. `keep`: без конвертации вообще |
| `--quality N` | качество при конвертации, по дефолту 95 |
| `--copy-icc` | скопировать ещё и цветовой профиль оригинала, подробнее ниже |
| `-f` | перезаписать результат, если он уже есть. Без флага утилита откажется |
| `--batch CSV` | обработать пачку |
| `-v` | показать все команды exiftool и sips, для дебага |

### Пачкой

Делаете CSV, в каждой строке пара `оригинал,обработанная`. Третьим полем можно указать, куда сохранить:

```csv
source,target,output
IMG_1234.HEIC,ai/IMG_1234_upscaled.png
IMG_1235.HEIC,ai/IMG_1235_upscaled.png
IMG_1240.HEIC,ai/portrait.webp,best/portrait.jpg
```

```sh
metacopy --batch pairs.csv -o done/
```

Что тут стоит знать:

- относительные пути считаются от папки, где лежит csv, а не от той, откуда запускаете
- заголовок и строки с `#` пропускаются
- разделитель можно и `;`, русский Excel сохраняет именно так. Если в пути есть запятая, возьмите его в кавычки
- если одна строка упала, остальные всё равно доедут. В конце будет `Готово: 4 из 5, ошибок: 1`, exit code при этом 1

## Что внутри

По сути это обёртка над exiftool, но с нормальными флагами и с починкой того, что после копирования начинает врать.

1. Копирует target во временную папку. PNG/WEBP при этом конвертятся в JPEG через `sips`, потому что Фото читают EXIF из PNG через раз. Прозрачность ложится на белый фон
2. `exiftool -all= --ICC_Profile:all` сносит все старые метаданные, кроме цветового профиля
3. `exiftool -TagsFromFile src -all:all -unsafe` переносит всё с оригинала: дату с таймзоной, GPS, камеру, объектив, Apple MakerNotes
4. Дальше правка:
   - `Orientation=1`. Айфон сохраняет пиксели как с матрицы и пишет `Rotate 90 CW`, а у нейронки они уже повёрнуты. Без этого все вертикальные фотки ложатся набок
   - `ExifImageWidth/Height` и размеры в XMP выставляются под реальный размер картинки
   - сносится IFD1 и PreviewImage, иначе кое-где вылезает миниатюра старой фотки
   - `ColorSpace` выставляется по тому профилю, который реально лежит в файле
5. `FileModifyDate` ставится равной дате съёмки с учётом `OffsetTimeOriginal`, чтобы при импорте ничего не съехало
6. Результат переносится на место, потом всё перечитывается и печатается отчёт. Если что-то не доехало, там будет `✗ не перенеслось`

Бэкапов `_original` после неё не остаётся: exiftool работает с `-overwrite_original`, но только над временной копией.

Без `sips` (то есть не на маке) конвертация пойдёт через Pillow, если он стоит. Для HEIC нужен именно `sips`.

### Про цветовой профиль

ICC оригинала по дефолту **не** копируется, и это сделано специально. У айфона там Display P3, а нейронки почти всегда отдают sRGB. Если навесить P3 на sRGB-пиксели, цвета уезжают в кислоту. Поэтому у картинки остаётся её собственный профиль.

`--copy-icc` нужен для обратной ситуации: тулза сохранила пиксели в P3, а профиль потеряла, и картинка выглядит блёклой по сравнению с оригиналом.

## Если что-то пошло не так

**Картинка легла набок.** В отчёте при этом будет `! у целевого файла было Orientation=…`. Значит, нейронка оставила тег поворота, а сами пиксели не повернула. Поверните её в Просмотре и прогоните ещё раз.

**Везде «нет в исходнике».** Скорее всего, оригинал потерял метаданные по дороге: телега и ватсап их вырезают. Берите оригинал через AirDrop или в Фото через Файл → Экспортировать → Экспорт немодифицированного оригинала.

**Непредвиденная ошибка.** Нормальные ошибки (битый файл, нет файла, не тот формат) выводятся одной строкой. Если вылезло что-то странное, запустите с `-v` и закиньте вывод в issues.

Коды выхода: `0` всё ок, `1` ошибка, `2` кривые аргументы, `130` прервали через Ctrl+C.

## Известные косяки

- `--copy-icc` вместе с `--format heic` не срабатывает, если у самой картинки не было профиля: exiftool не умеет добавлять ICC в такой HEIC. Утилита об этом предупредит, цвета останутся как у target
- проверял на macOS 15 с exiftool 13.59. На старых версиях не гонял, но ничего экзотического там не используется
- если Фото на какой-то версии macOS всё равно ставят картинку не на ту дату, пишите в issues, приложив вывод `exiftool -a -G1 файл`
